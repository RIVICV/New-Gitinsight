## 📌 Overview / 概述

**GitInsight AI** is a production-grade developer intelligence platform that transforms GitHub activity data into actionable engineering insights.

**GitInsight AI** 是一个生产级的开发者智能平台，将 GitHub 活动数据转化为可操作的工程洞察。

It combines:

它结合了：

- **📊 Real-time GitHub Analytics** — Comprehensive visibility into your development activity  
  **📊 实时 GitHub 数据分析** — 全面了解你的开发活动

- **📈 Engineering Intelligence** — Advanced metrics that measure productivity and consistency  
  **📈 工程智能** — 衡量生产力和一致性的高级指标

- **🤖 AI-Powered Insights** — Personalized recommendations for technical growth  
  **🤖 AI 驱动的洞察** — 个性化技术成长建议

- **🎯 Professional Portfolio Tools** — Generate resumes, READMEs, and release notes  
  **🎯 职业作品集工具** — 一键生成简历、README 和发布说明

## 🚀 Quick Start / 快速开始

### Prerequisites / 前置要求

- Node.js 18.x or higher / Node.js 18.x 或更高版本
- npm 9.x or higher / npm 9.x 或更高版本
- A GitHub account / 一个 GitHub 账号

### Installation / 安装

```bash
# Clone the repository / 克隆仓库
git clone https://github.com/RIVICV/New-Gitinsight.git
cd New-Gitinsight

# Install dependencies / 安装依赖
npm install

# Set up environment variables / 设置环境变量
cp .env.example .env.local
# Edit .env.local with your GitHub OAuth credentials
# 编辑 .env.local 填写你的 GitHub OAuth 凭证
```

### Running the Development Server / 运行开发服务器

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

打开 [http://localhost:3000](http://localhost:3000) 查看应用。

### Building for Production / 生产环境构建

```bash
npm run build
npm run start
```

### Data Flow / 数据流

1. **🔐 Authentication** — User signs in via GitHub OAuth  
   **🔐 认证** — 用户通过 GitHub OAuth 登录

2. **📊 Data Collection** — GitHub API fetches user, repo, and event data  
   **📊 数据收集** — GitHub API 获取用户、仓库和事件数据

3. **⚙️ Processing** — Analytics engine calculates engineering metrics  
   **⚙️ 处理** — 分析引擎计算工程指标

4. **📈 Visualization** — Recharts renders interactive dashboards  
   **📈 可视化** — Recharts 渲染交互式仪表盘

5. **🤖 AI Generation** — Context builder creates prompts from real data

6. **📝 Response** — AI-generated insights delivered to the user

## 🔐 Environment Variables / 环境变量

Create a `.env.local` file in the root directory:

在根目录创建 `.env.local` 文件：

```env
# GitHub OAuth
GITHUB_ID=your_github_client_id
GITHUB_SECRET=your_github_client_secret

# NextAuth
NEXTAUTH_SECRET=your_nextauth_secret
NEXTAUTH_URL=http://localhost:3000

# AI Service (optional, for production) / AI 服务（可选，用于生产环境）
DEEPSEEK_API_KEY=your_deepseek_api_key
```

### Setting up GitHub OAuth / 设置 GitHub OAuth

1. Go to **GitHub Settings → Developer settings → OAuth Apps**  
   进入 **GitHub 设置 → 开发者设置 → OAuth 应用**

2. Click **New OAuth App**  
   点击 **新建 OAuth 应用**

3. Fill in / 填写：
   - **Application name / 应用名称**: `GitInsight Dev`
   - **Homepage URL / 首页 URL**: `http://localhost:3000`
   - **Authorization callback URL / 授权回调 URL**: `http://localhost:3000/api/auth/callback`

4. Click **Register application** / 点击 **注册应用**

5. Copy **Client ID** and generate **Client Secret**  
   复制 **Client ID** 并生成 **Client Secret**

6. Add them to your `.env.local` file  
   将它们添加到你的 `.env.local` 文件中

### Generating NEXTAUTH_SECRET / 生成 NEXTAUTH_SECRET

```bash
openssl rand -base64 32
# Or use / 或者使用: node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```
